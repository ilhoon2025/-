# 한국 수능 부정행위! (Roblox 버전)

## 바로 열기
1. `SuneungCheat.rbxlx` 파일을 **Roblox Studio**로 엽니다 (파일 → 열기, 또는 더블클릭).
2. 위쪽 **▶ 플레이** → 처음 화면에서 **플레이하기**를 눌러야 입장합니다.

## 영역전개 사진 넣기 (한 번만)
Roblox는 외부 사진을 바로 못 쓰기 때문에 업로드가 필요해요.
1. Studio 상단 **보기 → 에셋 관리자(Asset Manager)** → **가져오기(Import)** 로 `domain.png` 업로드
   (또는 create.roblox.com → 개발자 아이템 → 데칼 업로드)
2. 업로드된 이미지를 우클릭 → **에셋 ID 복사**
3. `ReplicatedStorage > SuneungShared` 맨 위의 줄을 바꿉니다:
   ```lua
   Shared.DOMAIN_IMAGE = "rbxassetid://여기에_ID"
   ```
   ID가 `0`이면 사진 없이 대사만 나와요.

## 게임 방법
- 왼쪽 **✏️ 부정행위 적기!** 에 아무거나 적고 추가 → 고르고 **시험 시작**
- 내 캐릭터가 책상에 앉고 10문제(2분)를 풉니다.
- **🤫 부정행위 하기!** → 3초 동안 부정행위 → 성공하면 정답 힌트
- 시험지는 **학생마다 보기 순서가 달라서 정답 번호가 사람마다 다름**
  ("옆", "짝", "친구"가 들어간 부정행위는 옆사람 번호를 베끼는데… 대부분 틀림)
- 감독관의 **빨간 시야** 안에서 부정행위하면 적발 →
  감독관: **"료이키 텐카이 무량공처!"** → (검은 화면 없이) 사진이 잠깐 떴다 사라짐 → 들킨 학생은 **가루**
- AI 학생 없이, 서버에 들어온 플레이어들이 각자 빈 책상에 앉아 시험을 봐요. 감독관은 뉴비예요.

## 교실 밖
- 시험 중 **몰래 나가기**를 누르면 자리에서 일어나 걸을 수 있어요 (시험지는 잠시 숨겨짐).
- 교실 안에서 감독관 시야에 걸리면 적발, 감독관이 빈자리를 보면 의심도 +25 (100이 되면 적발).
- 오른쪽 **출입문** → 4차선 도로 → 길 건너 **매점**. 차에 치이면 죽고 시험은 실격 처리돼요.
- 매점 계산대에서 물건을 사고, 오른쪽 위 **가방**에서 먹으면 시험 중 효과가 있어요.
  (삼각김밥 의심도 -15, 컵라면 시간 +30초, 바나나우유/에너지드링크 다음 부정행위 성공률 증가 등)
- 처음 돈은 10,000원이에요. 자기 자리 가까이 와서 **자리로 돌아가기**를 누르면 다시 앉아요.

## 부정행위 전문점 (매점 옆, 보라색 건물)
- 계산대에서 E → 전자기기 30종 (스마트워치, 무선 이어폰, 스마트 안경, 뇌파 헤드밴드, 시간 정지 리모컨 …)
- **맞춤 제작**: 왼쪽 목록에서 고른 아무 물건이나 주문 가능 → 세상 모든 물건 구매 가능
- 산 물건은 "전문점 정품"이 되어 성공률 +25%, 적발 확률 -15%
- 처음 돈은 100,000원

## 업그레이드 전문점 (매점 왼쪽, 하늘색 건물)
- 장비 강화: 고른 부정행위 물건 성공률 +8%, 적발 확률 -5% (최대 +8)
- 살금살금 / 포커페이스 / 빠른 손: 몰래 이동 속도, 의심도 증가 감소, 부정행위 시간 단축
- 단계가 오를 때마다 가격 2배. 부정행위 전문점도 살 때마다 다음 물건 가격이 2배.

## 저격수 100명 (교실 지붕·가게 지붕·도로 양옆 감시탑)
- 빨간 레이저로 교실 밖(도로·가게 앞)을 훑음. 시험 중 몰래 나간 수험생만 노림
- 레이저가 천천히 훑다가 걸리면 조준점이 느리게 따라옴. 레이저가 몸에 3초 닿으면 저격 → 실격
- 계속 움직이거나 건물·차 뒤로 숨으면 피할 수 있음
- 시험 안 보는 플레이어와 교실·가게 안은 안전

## 1등급 엔딩
- AI 안경은 성공률 100% (항상 정답)
- 1등급을 받으면 서울대 합격 → 서울대 시험(5문제) → "인줄 알았는데......." → 회사 면접 → 마지막에 폭발로 사망

## 1등급 상품권 (맵 한쪽 구석에 하나)
- 교실 뒤쪽(칠판 반대편) 왼쪽 맨 끝 구석에 글씨 없는 금색 카드 → 가까이 가서 E로 줍기
- 시험 중 자리에 앉아서 가방의 **사용**을 누르면 바로 1등급 → 엔딩

## 탈 수 있는 차
- 내 차 모델을 Workspace에 넣고 이름을 **탈것** 으로 바꾸면 그 모델을 운전할 수 있음 (여러 개 가능)
- 교실 뒤 주차장에 차 50대 (탈것 모델이 있으면 그 모델을 복제, 없으면 뉴비 모양 차)
- 운전자가 죽으면 그 차는 원래 주차 칸으로 돌아감
- 가까이 가서 E(타기) → WASD 운전, Space로 내리기. 빠르게 달리면 다른 플레이어를 치어버림
- 앞뒤가 반대로 가면 모델의 속성(Attributes)에 `Reverse` (Boolean) 를 추가하고 체크

## 핵폭탄
- 위쪽 빨간 **핵폭탄 발사** 버튼 → 5초 뒤 교실 한가운데 떨어져 모든 플레이어 사망, 버섯구름 (60초에 한 번)

## 홍수 / 똥누기
- **홍수** 버튼: 물이 12칸 높이까지 차올랐다가 빠짐. 머리가 5초 넘게 잠기면 익사. 교실 뒤 벽 노란 사다리로 지붕에 올라가면 안전 (60초에 한 번)
- **똥누기** 버튼: 내 뒤에 똥이 생김 (30초 뒤 사라짐). 다른 사람이 밟으면 미끄러져 넘어짐. 시험 중이면 의심도 +10

## 핵 벙커
- 교실 안 뒤쪽 왼편 구석의 콘크리트 건물 (노랑·검정 경고 띠, "핵 벙커" 간판)
- 안에 있으면 핵폭탄과 홍수에도 안 죽음. 핵폭탄은 발사 후 10초 뒤 떨어짐

## 1등급 엔딩 전체 순서
서울대 합격 → 서울대 시험 → "인줄 알았는데......." → 회사 면접 → **군대 시험 → 인생 시험** → 폭발로 사망 → **천국 시험 → 할렐루야 시험** → 최종 결과 (70% 이상 맞히면 천국 입성, 아니면 환생해서 다시 수능)

## 파일 구성
| 파일 | Studio 위치 |
|---|---|
| `src/SuneungShared.lua` | ReplicatedStorage › ModuleScript `SuneungShared` |
| `src/SuneungServer.server.lua` | ServerScriptService › Script `SuneungServer` |
| `src/SuneungClient.client.lua` | StarterPlayer › StarterPlayerScripts › LocalScript `SuneungClient` |

`.lua`를 수정했다면 `python3 build_rbxlx.py` 로 `.rbxlx`를 다시 만들 수 있어요.
